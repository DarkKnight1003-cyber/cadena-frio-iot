# Evidencias

Coloca aquí capturas sin datos sensibles, por ejemplo:

- `mqtt-explorer.png`: tópicos de temperatura, humedad y alerta.
- `influxdb.png`: consultas al bucket `lecturas_iot`.
- `grafana-dashboard.png`: los tres paneles.
- `grafana-alerta.png`: la regla con estado Firing.
- `correo-alerta.png`: correo automático recibido (ocultar dirección personal si se desea).
- `aws-arquitectura.png`: subred pública, subred privada y reglas de seguridad.

**No incluir** capturas que muestren contraseñas, tokens, claves API ni el archivo privado `secrets.h`.
